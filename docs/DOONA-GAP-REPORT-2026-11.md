# DracPanel × doona 逐页对比报告（2026-11-02）

> 方法：浏览器实测 [doona 官方演示](https://demo.daeuniverse.org/#/activity)（v0.1.0-rc.4，mock 后端 honk v0.1.0-beta.4，含「编辑仪表盘」实测）× 本地面板 `pnpm dev + ?fixture=1`（23 条路由逐页 DOM 快照），并核对 [doona 官方文档](https://doona.daeuniverse.org/en/)（tour / features / observe / config-and-settings）。

## 0. 一句话结论

**信息架构与观测四件套（连接流量散点/分流拓扑/DNS 四标签/事件双标签）已与 doona 同构且质量相当；真正落后的是四处：活动页不可编辑、i18n 双轨制、配置/设置两页未拆、日志页过于简陋。** 另有一批 doona 级交互细节（行内加规则、深链、列宽调整、悬浮小面板）可作为增量吸收。

## 1. 双方硬实力对照

### 1.1 我们 ≥ doona 的部分（保持并宣传）

| 能力 | DracPanel | doona |
|---|---|---|
| 配置写入安全 | check→备份→原子写→健康检查→失败回滚 | 校验+诊断，无自动回滚事务 |
| 流量历史持久化 | 7 天落盘 `history.jsonl`，10m–7d 范围 | 历史功能依赖后端，重启受限 |
| 出口 IP 卡 | IP+国家+GeoIP 归属+机房质量 | 无此概念 |
| 连通性检测 | Google/GitHub/YouTube/ChatGPT 分服务延迟 | 无 |
| 系统集成 | 系统代理(GNOME/KDE)/TUN/局域网代理开关 | 无（引擎层职责） |
| eBPF 分应用策略 | off/blacklist/whitelist + uid 列表 | 无（honk 引擎自身接管） |
| DNS 上游探测 | 真实 UDP/TCP/TLS/DoH 计时 | 仅统计已有记录 |
| 主题 | 4 调色板×9 强调色×AMOLED×三模式 | 1 套配色 × 明暗 |
| 规则追踪模拟 | 静态求值 + 免责标注 | Trace（内核级，更强） |
| 订阅调度 | 定时更新 + 流量到期 | 手动/自动更新 |

## 3. 视觉风格对照（活动页截图）

- doona：深色双撞色（青=下载/激活、粉=品牌/上传辅助）、圆角 12–16px 扁平卡片、无轴 sparkline、数字优先层级、侧栏青色竖条指示当前页；瑕疵：灰字对比度偏低、搜索 placeholder 截断。
- DracPanel：FlClash 风（Dracula/Nord/Catppuccin 调色板）、同代扁平圆角卡、自绘 SVG 图表族（面积/环/散点/sparkline）与 doona 同级；活动页卡片密度高于 doona（状态+开关+连接流+策略组快切同页），部件化后密度问题自然解决。
